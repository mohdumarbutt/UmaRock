# Asset Replacement Instructions

Replace the following files with UmaRock branded versions:

## Required Asset Replacements

### 1. bot_image.jpg
- **Current:** Generic bot image
- **Replace with:** UmaRock logo
- **Specifications:** 512x512 pixels, JPG format
- **Content:** UmaRock logo with ⚡ theme emoji
- **Usage:** Bot profile picture and display image

### 2. stickintro.webp
- **Current:** Generic intro sticker
- **Replace with:** UmaRock branded intro sticker
- **Specifications:** WebP format, animated preferred
- **Content:** UmaRock Bot introduction sticker with ⚡ theme
- **Usage:** Welcome/intro messages

### 3. sticktag.webp
- **Current:** Generic tag sticker
- **Replace with:** UmaRock branded tag sticker
- **Specifications:** WebP format, animated preferred
- **Content:** UmaRock Bot tag notification sticker with ⚡ theme
- **Usage:** Tag/mention notifications

## Design Guidelines
- Use ⚡ (lightning bolt) as the primary theme emoji
- Include "UmaRock" or "UmaRock Bot" text
- Use modern, tech-style design
- Maintain consistency across all assets
- Ensure good visibility on both light and dark backgrounds

## File Locations
- `assets/bot_image.jpg` - Main bot image
- `assets/stickintro.webp` - Intro sticker
- `assets/sticktag.webp` - Tag sticker
